Using TOKINT

  

    
Look up a token
Enter a contract and token ID, then press Enter or the search icon. Refresh fetches current contract data, metadata, and media. Recent tokens reuse locally cached files when available; the trash icon clears recents and cache.

    
From the browser
Type tokint Tab in the address bar, followed by:
address tokenId
Inspect a token
address
Read the contract on Etherscan
CID/path or ipfs://CID/path
Open the configured IPFS gateway (gateway URLs also work)
All address-bar commands work in TOKINT; no companion extension is needed.
Click the tokint toolbar button on OpenSea, SuperRare, or any page with /contract-address/token-ID in its URL path. Links without a network label are treated as Ethereum mainnet.

    
Storage badges
On-chain: JSON returned directly as a data URI, or image bytes embedded in that JSON.
Decentralized: IPFS or a recognized Arweave gateway.
Centralized: another HTTP host.
Media describes the selected media source. Images embedded in remote JSON inherit its storage type. Badges describe the URI, not permanence or external dependencies inside the artwork.

    
Media & browsing
When metadata includes multiple media assets, use Media source to switch between them. The download icon uses the selected asset for originals or smaller JPEG, GIF, and WebP exports. Embedded HTML animations load in an isolated preview; canvas animations can be exported as GIF or WebP. Video and audio can be opened using the source link. The expand icon opens the selected media full screen. Enable Alchemy in Settings for collection and wallet browsing, plus ownership and mint details.

    
Privacy
Lookups go directly to your selected providers and artwork hosts. Media conversion runs locally, and recent tokens are stored in this browser. Read the privacy policy.
