Alchemy enables collection and wallet browsing plus ownership and mint details. These features are hidden with other providers.

Paste your Ethereum mainnet HTTPS RPC URL from the Alchemy dashboard ↗. Enables collection/wallet browsing and ownership/mint details. Requires NFT API access.

Warning: saves this RPC URL and any API key unencrypted in your browser profile. Anyone with access to that profile may be able to read it. Leave unchecked to use it only for this browser session.

Base URL only, without /ipfs/. Use HTTPS; HTTP is allowed only for localhost or 127.0.0.1.

Select Custom gateway to edit the URL and style.

Use tokint Tab in the address bar with an Ethereum address, address + token ID, or IPFS CID/path.

Preferences, recent tokens, and cached artwork are saved locally without encryption. Alchemy and custom RPC URLs stay in memory unless you choose Remember on this device. Lookups go directly to your selected providers and artwork hosts; media conversion runs locally. HTML artwork stays paused until you consent to running its code, which may contact external or local services and reveal your IP address. New content hosts may ask for access. Privacy policy.
