# Token service logos

The media footer links to the currently submitted Ethereum token on OpenSea and
OnChainChecker. Logos are bundled locally; displaying the links does not request
either service. Links open in a new tab with `noopener noreferrer`.

- `public/icons/opensea.svg`: OpenSea's circular sailing-ship mark, extracted from
  the OpenSea home link on https://opensea.io/ on October 18, 2026. Original paths
  and colors retained; page-specific class and style attributes removed.
- `public/icons/onchainchecker.png`: downloaded unchanged from
  https://onchainchecker.xyz/brand/occ-logo.png on October 18, 2026.
  Integration guidance and URL format: https://onchainchecker.xyz/about.

Ethereum token URLs:

```text
https://opensea.io/item/ethereum/{contract-address}/{token-id}
https://onchainchecker.xyz/collection/ethereum/{contract-address}/{token-id}
```

These marks identify the linked services and do not imply affiliation.
